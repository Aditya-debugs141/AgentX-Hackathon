## AgentX custom HTTP streaming protocol

This request is made through a custom HTTP gateway that forwards Server-Sent Events. The gateway requests `stream: true` and forwards every SSE frame immediately; it does not want only the final answer after the task completes.

During execution, emit machine-readable SSE JSON events as soon as each state change occurs. Use these event shapes where applicable:

{"type":"execution","execution":{"planner":"Nemotron Planner","agents":[{"name":"Knowledge Agent","status":"running"}],"trace":["Planner received request","Knowledge Agent started"]}}

{"type":"trace","trace":"Knowledge Agent searched the campus handbook"}

{"type":"agent_status","agent":{"name":"Knowledge Agent","status":"completed"}}

{"type":"card","card":{"type":"event","payload":{"title":"...","date":"...","location":"...","registered":true}}}

{"type":"source","source":{"title":"...","url":null}}

Emit progress in this order whenever the operation applies: planner received request, delegation started, each worker/tool started, each worker/tool completed, and planner synthesis started/completed. Do not wait until the final answer to emit these events. Never expose private chain-of-thought; emit concise operational progress only.

After all progress events, emit the final assistant content through the normal OpenAI-compatible delta stream and finish with the provider's normal stream terminator. Keep event JSON valid and do not wrap it in Markdown.
